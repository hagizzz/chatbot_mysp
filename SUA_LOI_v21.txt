================= MỚI Ở v21 =================
[Duyên Phận + LUẬT SIZE CŨ] (nhánh tư vấn size ~9554) — sửa "tư vấn 1 kiểu chốt 1 kiểu" + ưu tiên size cũ:
   - LỖI cũ: khách có size cũ tự khai (vd L), cân mới ra M -> bot TƯ VẤN M nhưng KHÔNG cập nhật
     mem.customerSize -> ĐƠN vẫn lấy L (size cũ) -> tư vấn M chốt L (lệch).
   - SỬA: 
     * Cân mới + 2kg (chênh tối đa ~3kg) VẪN ra size cũ -> ƯU TIÊN GIỮ size cũ.
       VD: 54kg, 54+2=56 -> L == size cũ L => "Dạ với 54kg thì chị mặc size L là chuẩn form nhất ạ..."
     * Nếu +2kg KHÔNG ra size cũ -> tư vấn theo size MỚI.
     * Khách KHÔNG có size cũ -> theo code mặc định (vd 54kg -> M).
     * LUÔN set mem.customerSize = size VỪA TƯ VẤN -> CHỐT đúng size đã tư vấn (hết lệch tư vấn/đơn).
   - Đã unit-test 7/7 ca (Duyên 54+L->L; 53+L->M; no-old 54->M; ...).
